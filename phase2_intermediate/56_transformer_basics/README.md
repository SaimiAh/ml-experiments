# Transformer Architecture Simplified
This is a simplified implementation of the Transformer architecture, suitable for understanding the core concepts and mechanics behind this popular deep learning model. Use this when you want to explore the fundamentals of Transformers without getting bogged down in complex configurations.

* Attention mechanisms
* Self-attention and cross-attention
* Encoder-decoder structure
* Simplified training loop

## How to Run
To run this experiment, simply execute: `python main.py`
