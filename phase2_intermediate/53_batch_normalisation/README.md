# Batch Normalisation Explained
Batch Normalisation is a technique used to normalise the inputs of each layer in a neural network, typically used to improve training speed and stability. It is particularly useful when dealing with deep neural networks or large datasets.

* Normalisation of inputs
* Reduction of internal covariate shift
* Improved training speed
* Stability of training process
