# Reinforcement Learning — Q-learning basics
This is a basic implementation of Q-learning, a reinforcement learning technique used to train agents to make decisions in complex environments. Q-learning is useful when the environment is fully observable and the agent needs to learn a policy to achieve a goal.

* Q-table: a data structure to store the expected return for each state-action pair
* Exploration-exploitation trade-off: balance between trying new actions and choosing the best known action
* Learning rate: controls how quickly the agent learns from new experiences
* Discount factor: determines the importance of future rewards

To run the experiment, use `python main.py`
