# Variational Autoencoders (VAE) Experiment - Day 59
This experiment explores Variational Autoencoders, a type of deep learning model that learns to compress and reconstruct data. VAEs are useful when you want to reduce dimensionality, generate new data, or learn a continuous and structured representation of your data.

* Latent space representation
* Encoder-decoder architecture
* KL divergence loss
* Generative capabilities
