# Ensemble Methods
This experiment explores ensemble methods, specifically stacking and blending, which combine multiple models to improve performance. Use these techniques when a single model is not sufficient or to reduce overfitting.

* Stacking: training a meta-model on predictions of base models
* Blending: combining predictions of multiple models using weights
* Ensemble methods reduce variance and improve overall performance
* Increased complexity requires careful tuning of hyperparameters

How to run: `python main.py`
