# NLP Basics: TF-IDF and Text Vectorisation
This experiment covers the fundamentals of NLP using TF-IDF and text vectorisation, essential techniques for text analysis and information retrieval. Use TF-IDF when you need to transform text into numerical vectors for machine learning models.

* TF-IDF: weighing word importance in documents
* Text Vectorisation: converting text into numerical vectors
* Term Frequency: word frequency in a document
* Inverse Document Frequency: word rarity across documents

To run the experiment, use `python main.py`
