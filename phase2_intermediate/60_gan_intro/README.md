# Generative Adversarial Networks — intro
Generative Adversarial Networks (GANs) are a type of deep learning model used for generating new, synthetic data that resembles existing data. They can be used when you want to generate new data, such as images, videos, or music, that is similar to a given dataset.

* Generator network
* Discriminator network
* Adversarial loss function
* Minimax optimization

## How to run
`python main.py`
