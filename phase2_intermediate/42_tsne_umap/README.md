# Dimensionality Reduction Experiment
This experiment compares t-SNE and UMAP for dimensionality reduction, a technique used to simplify complex data for easier analysis and visualization. 

* t-SNE: non-linear technique for preserving local structures
* UMAP: non-linear technique for preserving global structures
* Dimensionality reduction: simplifying complex data
* Data visualization: representing data in a lower-dimensional space

To run the experiment: `python main.py`
