# Autoencoders for Dimensionality Reduction
This experiment explores the use of autoencoders for dimensionality reduction, a technique used to reduce the number of features in a dataset while retaining most of the information. Autoencoders are useful when dealing with high-dimensional data and wanting to visualize or analyze it in a lower-dimensional space.

* Dimensionality reduction
* Autoencoders
* Neural networks
* Data compression

To run the experiment, use: `python main.py`
