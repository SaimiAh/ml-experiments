# Three Learning Principles — Occam Sampling Snooping
This experiment explores the combination of Occam, Sampling, and Snooping learning principles. Use this when seeking to simplify complex models while accounting for uncertainty and actively querying the data.

* Occam's Razor: favoring simpler models
* Sampling: accounting for data uncertainty
* Snooping: active querying of the data
* Model comparison: evaluating competing models

To run: `python main.py`
