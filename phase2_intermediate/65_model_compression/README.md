# Model Compression Experiment
Model compression through pruning and quantisation is a technique used to reduce the size of machine learning models, making them more efficient and suitable for deployment on edge devices. This is particularly useful when working with large models that require significant computational resources.

* Pruning: removing redundant or unnecessary weights
* Quantisation: reducing precision of model weights
* Compression ratio: measure of model size reduction
* Inference speedup: increase in model execution speed

Run the experiment using: `python main.py`
