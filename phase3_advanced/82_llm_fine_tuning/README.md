# LLM Fine-Tuning - LoRA Explained
This experiment explores LoRA (Low-Rank Adaptation) for fine-tuning large language models (LLMs), useful when adapting a pre-trained model to a specific downstream task. 

* LoRA: Low-Rank Adaptation of weights
* Fine-tuning: adapting pre-trained models to downstream tasks
* LLMs: Large Language Models

To run the experiment, use: `python main.py`
