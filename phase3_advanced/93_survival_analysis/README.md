# Survival Analysis Experiment
Survival analysis is a type of time-to-event modelling, used to predict the time until a specific event occurs. It's commonly applied in fields like healthcare, finance, and social sciences when the main interest is the time to occurrence of an event.

* Censoring: incomplete data due to limited observation time
* Hazard function: describes the likelihood of an event
* Kaplan-Meier estimator: non-parametric method for estimating survival curves
