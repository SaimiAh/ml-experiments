# Support Vector Machine Experiment
This is a day 13 experiment on Support Vector Machine, a supervised ML model used for classification and regression tasks. Use it when you need a robust model that can handle high-dimensional data and non-linear relationships.

* Maximizing margin between classes
* Hyperplane and decision boundary
* Kernel trick for non-linear data
* Regularization for overfitting

# How to run
Run the experiment using: `python main.py`
