# Backpropagation Explained with Code
This is a machine learning experiment that demonstrates the concept of backpropagation. It is useful when training neural networks, especially during the training phase when adjusting model weights.

* **Neural Networks**: Basic understanding of neural networks and their architecture
* **Gradient Descent**: Method used to optimize model weights
* **Weight Updates**: Adjusting model weights based on calculated gradients
* **Optimization**: Minimizing loss function using backpropagation

### How to Run
To run this experiment, execute the following command: `python main.py`
