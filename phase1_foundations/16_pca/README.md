# Principal Component Analysis (PCA) - Day 16
Principal Component Analysis (PCA) is a dimensionality reduction technique used to reduce the number of features in a dataset while retaining most of the information. It is useful when dealing with high-dimensional data and helps to visualize and understand the underlying patterns.

* Dimensionality reduction
* Feature extraction
* Data visualization
* Noise reduction
