# ML Experiment: Train/Test Split and Overfitting
This experiment explores the importance of train/test split and overfitting in machine learning, demonstrating when to use these techniques to improve model performance.

* Train/Test Split: dividing data into training and testing sets
* Overfitting: when a model is too complex and performs well on training data but poorly on testing data
* Model Evaluation: assessing model performance using metrics such as accuracy and loss

To run the experiment, use: `python main.py`
