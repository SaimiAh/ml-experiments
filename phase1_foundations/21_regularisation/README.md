# L1 vs L2 Regularisation — Ridge and Lasso
This experiment explores the differences between L1 and L2 regularisation using Ridge and Lasso regression. It's useful when dealing with overfitting, and helps to understand when to use each type of regularisation.

* L1 Regularisation (Lasso) sets model weights to zero, performing feature selection
* L2 Regularisation (Ridge) reduces model weights, but doesn't set them to zero
* Regularisation helps prevent overfitting
* Model performance is compared using metrics like Mean Squared Error

To run: `python main.py`
