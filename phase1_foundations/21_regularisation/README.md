# L1 vs L2 Regularisation — Ridge and Lasso
This experiment explores the differences between L1 and L2 regularisation techniques, specifically Ridge and Lasso regression. Use these techniques to prevent overfitting in linear regression models.

* L1 Regularisation (Lasso): reduces model complexity by setting coefficients to zero
* L2 Regularisation (Ridge): reduces model complexity by shrinking coefficients
* Regularisation techniques help improve model generalisation

To run: `python main.py`
